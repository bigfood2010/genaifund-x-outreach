# LLM provider facts, xAI Grok API and Google Gemini API

Date 2026-11-16. Tools used were Context7 (resolve-library-id, query-docs), Exa (web_fetch_exa, web_search_exa), Tavily (tavily_extract, tavily_search), WebFetch (one call), and Bash with jq only to read oversized Tavily outputs that the harness had saved to disk. No paid API was called. No recommendation is made in this file.

Tag meaning. Verified means I read the claim on the primary page during this pass. Reported means a secondary source or a summary only. Assumed means no source, usually my own arithmetic.

Naming note. docs.x.ai now brands itself SpaceXSI Docs, and the Enterprise terms name the contracting party SpaceX Super Intelligence LLC. This file still says xAI because the question does. Google moved the Gemini docs to aistudio.google.com/docs, and ai.google.dev/gemini-api/docs still serves a mirror. I read both and say which one per row.

Tool failures worth knowing. Exa could not read docs.x.com (SOURCE_NOT_AVAILABLE) or ai.google.dev (timeout), so those pages came through Tavily. Quotes are kept under 15 words and some use an ellipsis.

## Conflicts between sources

1. Rate limit units. The question assumed RPM. xAI publishes RPS and TPM and says RPS is derived from RPM divided by 48. Treat any RPM figure as derived.

2. xAI free credits on signup. The current quickstart says to load an account with credits and does not mention a signup credit. Two third-party guides (2026-02-21 and 2026-10-16) say new accounts get 25 USD that expires in 30 days. Official pages do not confirm or deny this.

3. xAI data sharing program. The official page is a 404 today and absent from llms.txt. Mirrors and a 2026-10-16 guide describe it as live. Other secondary sources say it ended in May 2025. No primary source settles it.

4. xAI Chat Completions status. The comparison page labels it "Deprecated". The API reference calls it a predecessor. Yet the structured outputs page and the rate limits page still show chat.completions code. The docs push Responses but keep the old examples.

5. xAI reasoning effort values for grok-4.3. The model page lists none through xhigh. The models page text lists none, low, medium, high.

6. xAI branding and legal entity. Pages say SpaceXSI or SpaceXAI. The Enterprise terms name SpaceX Super Intelligence LLC, and older terms versions name X.AI LLC. The question and many third-party pages say xAI.

7. X redistribution cap for hydrated objects. The Developer Policy page says up to 500 public Post or User Objects per person per day by non-automated means. The Guidelines and the restricted use page say 50,000 per recipient per day.

8. X page routing and DM strictness. The agreement-and-policy URL shows the Policy, not the Agreement. The Policy needs explicit consent before automated DMs. The Guidelines state the tighter rule that automated DMs are allowed only after the user DMs first.

9. Gemini rate limits mirror. aistudio.google.com/docs/rate-limits shows a Tier 2 spend limit of 200 USD per 10 minutes and adds that some free projects need verification. The ai.google.dev copy, last updated 2026-10-15, shows 50 USD and omits the verification note.

10. Gemini free tier data use. The pricing page says free content is used to improve products with no regional note. The Terms say users in the EEA, Switzerland and the UK get the Paid Services data terms even on unpaid quota. This refines the known fact.

11. Gemini 2.5 and 3.1 models. The pricing page still lists gemini-2.5-pro and gemini-2.5-flash as free and gemini-3.1-flash-lite with prices. The deprecations page says the first two are unavailable to select and the third shuts down 2027-05-07. One blog notes the same mismatch for 2.5 Pro.

12. Gemini free-tier numbers. Google says view them in AI Studio only. One blog gives numbers from its own project. No official public table exists to check them against.
